## Run tasks

To run the dev server for your app, use:
npm install

```sh
npx nx serve cow-catalog-app
```

To create a production bundle:

```sh
npx nx build cow-catalog-app
```

To see all available targets to run for a project, run:

```sh
npx nx show project cow-catalog-app
```

Area of Choices :
Used Nx Monorepo - to have separate lib
clear boundaries between features
so that it could be scaled in future
separation of concern - feature logic is separated into libraries rather than loading everthing in app shell.

Have not used shared or core libs - as its not that heavy application : to make it clean and lean.

Facade for State Access - as its god approach not to call services directly in component - introduced facade
this makes components clean and thin
centralised data handling - as it provided decoupling

Avoided NgRx for scope - due to limited domain complexity. - Global Store would have added boilerplate - reactive state using local Storage and behavior Subject was sufficient

Usage of Dynamic form using Formly
PrimeNg is used for data tables, cards, dialogs, timelines

Used Standalone components - reduced boiler plate, no modules needed, better lazy loading

APP Hosted : https://nancyp1994.github.io/cow-catalog/

## Add new projects

While you could add new projects to your workspace manually, you might want to leverage [Nx plugins](https://nx.dev/concepts/nx-plugins?utm_source=nx_project&utm_medium=readme&utm_campaign=nx_projects) and their [code generation](https://nx.dev/features/generate-code?utm_source=nx_project&utm_medium=readme&utm_campaign=nx_projects) feature.

Use the plugin's generator to create new projects.

To generate a new application, use:

```sh
npx nx g @nx/angular:app demo
```

To generate a new library, use:

```sh
npx nx g @nx/angular:lib mylib
```

You can use `npx nx list` to get a list of installed plugins. Then, run `npx nx list <plugin-name>` to learn about more specific capabilities of a particular plugin. Alternatively, [install Nx Console](https://nx.dev/getting-started/editor-setup?utm_source=nx_project&utm_medium=readme&utm_campaign=nx_projects) to browse plugins and generators in your IDE.
